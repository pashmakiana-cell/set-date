# 💌 Date Invitation App

یک اپ استریم‌لیت که یه سناریوی دیت‌خواستنِ رمانتیک رو پیاده می‌کنه.

## اجرا

```bash
pip install -r requirements.txt
streamlit run app.py
```

بعد از اجرا، آدرس چیزی شبیه `http://localhost:8501` باز می‌شه.

## نحوه کار

### مرحله ۱ — پسر
1. وارد سایت (بدون هیچ پارامتری) می‌شه، فرم رو پر می‌کنه:
   - نحوه‌ی ارسال جواب: تلگرام (یوزرنیم) یا پیامک (شماره)
   - اسم طرف مقابل (اختیاری، برای شخصی‌سازی)
   - چند زمان پیشنهادی برای دیت
2. روی «لینک دعوت‌نامه رو بساز» می‌زنه و یک کد کوتاه (مثلا `?id=ab12cd34ef`) می‌گیره.
3. این پارامتر رو به آدرس سایت (بعد از دیپلوی) اضافه می‌کنه و از هر طریقی
   که خودش دوست داره (تلگرام، واتساپ، پیامک...) برای طرف مقابل می‌فرسته.

### مرحله ۲ — دختر
با باز کردن لینک (`.../?id=...`) وارد یک تجربه‌ی ۴ مرحله‌ای می‌شه:

1. **Yes / No** — سوال «با من میای دیت؟». دکمه‌ی No هر بار که کلیک بشه:
   - یک متن بامزه‌ی تصادفی نشون می‌ده
   - جای دیگه‌ای روی صفحه می‌پره (فرار می‌کنه!)
   - و دکمه‌ی Yes هر بار بزرگ‌تر می‌شه
   بعد از ۹ بار کلیک، دکمه‌ی No کلاً ناپدید می‌شه 😉
2. **انتخاب زمان** — از بین زمان‌هایی که پسر وارد کرده، یکی رو انتخاب
   می‌کنه؛ زیرش تاریخ و ساعت به‌صورت شمسی هم نشون داده می‌شه.
3. **انتخاب مکان** — کافه، رستوران، پارک/قدم‌زدن، شهربازی، رانندگی،
   سینما، خرید یا «سورپرایزم کن».
4. **پیشنهاد اختیاری** — یک تکست‌باکس برای پیشنهاد مکان دلخواه (یا رد کردن).
5. **جدول نهایی** — همه‌چیز جمع‌بندی می‌شه و یک دکمه ظاهر می‌شه که با یک
   کلیک، خلاصه‌ی جواب رو (با متن و ایموجی آماده) در تلگرام یا اپ پیامک
   باز می‌کنه تا برای پسر ارسال بشه.

## نکات فنی

- ذخیره‌سازی دعوت‌نامه‌ها در یک فایل ساده‌ی `matches.json` کنار
  `app.py` انجام می‌شه (برای دیپلوی جدی‌تر می‌شه به یک دیتابیس واقعی
  مثل SQLite/Postgres مهاجرت کرد).
- ارسال جواب از طریق **دیپ‌لینک** انجام می‌شه، نه API؛ یعنی نیازی به
  توکن ربات تلگرام یا سرویس پیامکی نیست:
  - تلگرام: `https://t.me/<username>?text=...`
  - پیامک: `sms:<phone>?&body=...`
  این یعنی خود دختر روی دکمه کلیک می‌کنه و اپ گوشیش با پیام آماده باز
  می‌شه؛ کافیه دکمه‌ی ارسال رو بزنه.
- تبدیل تاریخ به شمسی با کتابخانه‌ی `jdatetime` انجام می‌شه.
- برای دیپلوی عمومی می‌تونی از [Streamlit Community Cloud](https://streamlit.io/cloud)
  استفاده کنی؛ فقط توجه کن که `matches.json` روی هاست‌های stateless
  ممکنه بین دیپلوی‌ها پاک بشه — برای پایداری بیشتر یک دیتابیس واقعی
  (مثلاً Supabase/SQLite با volume) جایگزین کن.

## شخصی‌سازی بیشتر

- برای اضافه کردن عکس‌های واقعی، یک پوشه‌ی `assets/` بساز و در
  `stage_yes_no` / بقیه‌ی صفحات با `st.image("assets/xxx.jpg")` یا
  `<img src="...">` داخل بلوک‌های HTML اضافه‌شون کن.
- متن‌ها، ایموجی‌ها و گزینه‌های مکان (`LOCATION_OPTIONS`) و جملات
  دکمه‌ی No (`NO_BUTTON_MESSAGES`) در بالای `app.py` قابل ویرایش‌ان.
