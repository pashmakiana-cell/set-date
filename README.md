# 💌 Date Invitation App

A romantic **Streamlit app** for creating personalized date invitations.

🔗 **Live Demo:** [our-date-pashmakiana.streamlit.app](https://our-date-pashmakiana.streamlit.app/)

## ✨ Features

- 💌 Create personalized invitations
- 🗓️ Add date & time options
- 💖 Interactive Yes / No invitation
- 📍 Choose a date location
- 📝 Add an optional note
- 🇮🇷 Shamsi & Gregorian date support
- 📨 Send the answer via Telegram or SMS
- 💾 JSON-based storage

## 🛠️ Built With

- Python
- Streamlit
- Jdatetime
- JSON

## 🚀 Run

```bash
git clone https://github.com/pashmakiana-cell/set-date.git
